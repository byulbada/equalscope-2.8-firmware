| | 쓰는 곳 |

| **별바다랩** (BYULBADA LAB) | **장비 브랜드.** 카페 · 스마트스토어 · 제품 · 홍보물 — 기본은 이쪽 |

«별바다랩» 을 쓰지 말 것 — 그 자리는 등록된 상호여야 한다.

## 색

| 용도 | HEX |
|------|-----|
| 주황 (별) | `#FF6600` |
| 파랑 (파도) | `#0099FF` |
| 워드마크 · 어두운 배경 (navy) | `#0D2137` |
| 태그라인 (밝은 배경) | `#5B7186` |
| 태그라인 (어두운 배경) | `#9FB3C8` |

로고 컨셉 = **별(★) + 파도(🌊)**. 별 = 주황, 파도 = 파랑.
워드마크 글꼴 = **Montserrat SemiBold**. ★ SVG 안에서는 **패스로 변환**되어 있어
받는 쪽에 폰트가 없어도 똑같이 나온다(인쇄소·쇼핑몰에 그대로 넘겨도 된다).

## 별바다랩 로고 (`byulbada-lab_*.svg`)

### 짜임 셋

| 이름 | 생김새 | 쓰는 곳 |
|---|---|---|
| `stacked` | 심볼 위, 워드마크 두 줄 **가운데 정렬** | 기본형. 정사각·세로 자리 |
| `horizontal` | 심볼 왼쪽, 워드마크 두 줄 **왼쪽 정렬** | 머리글·명함·간판 |
| `oneline` | 심볼 + **한 줄** BYULBADA LAB | 아주 좁은 자리(웹 머리글·각인) |

### 고르는 법

```
byulbada-lab_<짜임>[_notag][_색].svg
```

- `_notag` = **EXPLORE FURTHER 없는** 판. 작게 쓸 때는 이쪽이 낫다.
- 색 없음 = 밝은 배경 · 워드마크 **네이비** ← **기본으로 이것을 쓴다**
- `_black` = 밝은 배경 · 워드마크 **검정**
- `_dark` = 어두운 배경 · 워드마크 **흰색**
- `_mono-navy` / `_mono-black` / `_mono-white` = **한 색**. 각인 · 자수 · 도장 ·
  팩스처럼 색을 못 쓰는 자리. ★ 단색이어도 파도는 **비워진 선**으로 남아 읽힌다.

### 최소 크기 · 여백

| | 최소 |
|---|---|
| `stacked` | 폭 20mm (인쇄) / 80px (화면) |
| `horizontal` | 폭 30mm (인쇄) / 120px (화면) |
| `oneline` | 폭 26mm (인쇄) / 104px (화면) |
| 심볼 단독 | 폭 8mm / 32px |

여백(clear space) = **심볼 폭의 1/4** 이상을 사방에 비운다.
⛔ 로고 안의 간격을 손으로 바꾸지 말 것 — 아래 생성기가 비율로 잡는다.

## 다시 굽기

로고 SVG 는 **손으로 고치지 않는다.** 비공개 repo 의 생성기를 고치고 다시 굽는다.

```
python tools/gen_brand_logo.py      # eqtool_2.8_espidf
```

심볼을 다시 그리면 로고 전부가 따라온다(생성기가 이 폴더의 심볼을 읽는다).
자세한 규칙은 그 파일 머리 주석에 있다.
