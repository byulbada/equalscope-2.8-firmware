| | 쓰는 곳 |

«별바다랩» 을 쓰지 말 것 — 그 자리는 등록된 상호여야 한다.

## 색

| 용도 | HEX |
|------|-----|
| 주황 (별) | `#FF6600` |
| 파랑 (파도) | `#0099FF` |
| **워드마크 · 태그라인 남색** | `#053365` |
| 어두운 배경 (navy) | `#0D2137` |

★ **태그라인도 워드마크와 같은 색이다**(별님 2026-09-19). 시안은 연한 회청색이었는데
같은 색으로 가기로 했다. 어두운 배경에서는 둘 다 흰색.

⚠️ **남색이 둘이다 — 하는 일이 다르다.** `#053365` 는 **글자색**(워드마크),
`#0D2137` 은 **바탕색**(어두운 배경·theme-color). 시안의 워드마크 색이 바탕 남색보다
푸르러서, 별님이 시안 색을 그대로 가기로 했다(2026-09-19). ⛔ 하나로 합치지 말 것.

로고 컨셉 = **별(★) + 파도(🌊)**. 별 = 주황, 파도 = 파랑.
워드마크 글꼴 = **Montserrat SemiBold**. ★ SVG 안에서는 **패스로 변환**되어 있어
받는 쪽에 폰트가 없어도 똑같이 나온다(인쇄소·쇼핑몰에 그대로 넘겨도 된다).

## 별바다랩 로고 (`byulbada-lab_*.svg`)

### 짜임 셋

| 이름 | 생김새 | 쓰는 곳 |
|---|---|---|
| `stacked` | 심볼 위, 워드마크 **가운데 정렬** | 기본형. 정사각·세로 자리 |
| `horizontal` | 심볼 왼쪽, 워드마크 **왼쪽 정렬** | 머리글·명함·간판 |
| `oneline` | 심볼 + **한 줄** BYULBADA LAB | 아주 좁은 자리(웹 머리글·각인) |

★ **치수·자간·색은 시안을 픽셀로 재서 옮겼다** — 심볼 대비 글자 크기, 두 줄 사이,
태그라인 크기까지 전부 비율로 들어 있다. 눈대중이 아니다.
★ **BYULBADA 와 LAB 의 자간이 다르다**(−0.026em / +0.041em). 글자가 셋뿐인 LAB 은
같은 자간이면 빽빽해 보여서 시안이 벌려 두었다. ⛔ 둘을 같게 맞추지 말 것.
★ **태그라인은 워드마크와 「글자 시작~끝」이 정확히 같다** — 글자 상자가 아니라
**눈에 보이는 획**을 기준으로 맞춘다(상자로 맞추면 좌우 여백만큼 안쪽에서 끝난다).
★ 한글은 문구가 짧아 그 폭에 맞추려면 자간을 좁혀야 한다. **획이 닿기 직전까지**
좁히고(가장 좁은 짝 `RT` 기준), 그래도 넘치면 그때 크기를 줄인다.
★★ **가로형에서 태그라인 바닥 = 심볼 바닥** (별님 규칙). 두 줄은 심볼의 상하 가운데에
놓이고 태그라인이 그 아래를 채운다. ⇒ **태그라인이 있든 없든 잠금의 높이가 심볼
높이 그대로**라, 머리글·띠 배너에 앉힐 때 자리가 안 흔들린다.
세로형의 태그라인 간격도 **같은 값**을 쓴다(두 짜임의 인상이 같아진다).

### 고르는 법

```
byulbada-lab_<짜임>[_ko][_notag][_색].svg
```

- `_ko` = **한글 워드마크(별바다랩)** 판. 네이버·카페·스마트스토어처럼 한글이
  먼저인 자리. 글꼴은 **Pretendard SemiBold**, 태그라인은 영문 그대로 둔다.
  ★ 한글 크기는 **옛 별바다다이브 「가로형」 로고와 같은 비율**이다
  (한글 높이 = 심볼 높이의 **0.400**). ⚠️ 옛 **세로형**은 0.256 인데, 그건 한글이
  여섯 글자라 심볼 아래에 눕히려고 작게 쓴 것이다 — **가로형이 기준**이다.
  심볼은 한·영이 **같은 크기**라 두 판이 형제로 보인다.
  ★ 한글이 이 크기라야 태그라인도 영문과 **같은 크기**로 설 수 있다(작으면 태그라인이
  그 폭에 맞추느라 같이 작아진다).
- `_notag` = **EXPLORE FURTHER 없는** 판. 작게 쓸 때는 이쪽이 낫다.
- 색 없음 = 밝은 배경 · 워드마크 **남색** ← **기본으로 이것을 쓴다** (별님 확정)
- `_dark` = 어두운 배경 · 워드마크 **흰색**
- `_mono-navy` / `_mono-black` / `_mono-white` = **한 색**. 각인 · 자수 · 도장 ·
  팩스처럼 색을 못 쓰는 자리. ★ 단색이어도 파도는 **비워진 선**으로 남아 읽힌다.

### 최소 크기 · 여백

| | 최소 |
|---|---|
| `stacked` | 폭 20mm (인쇄) / 80px (화면) |
| `horizontal` | 폭 30mm (인쇄) / 120px (화면) |
| `oneline` | 폭 26mm (인쇄) / 104px (화면) |
| 심볼 단독 | 폭 8mm / 32px |

여백(clear space) = **심볼 폭의 1/4** 이상을 사방에 비운다.
⛔ 로고 안의 간격을 손으로 바꾸지 말 것 — 아래 생성기가 비율로 잡는다.

## 다시 굽기

로고 SVG 는 **손으로 고치지 않는다.** 비공개 repo 의 생성기를 고치고 다시 굽는다.

```
python tools/gen_brand_logo.py      # eqtool_2.8_espidf
```

심볼을 다시 그리면 로고 전부가 따라온다(생성기가 이 폴더의 심볼을 읽는다).
자세한 규칙은 그 파일 머리 주석에 있다.
