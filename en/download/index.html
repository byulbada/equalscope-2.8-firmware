Downloads

Update over a USB cable or with an SD card — neither way needs any software installed on your PC.

USB cable .uf2

  1. Connect the device to your PC with a USB cable.
  2. Settings → hold USB for 1.5 s → [Firmware Update].
  3. Drop the .uf2 file onto the EQ UPDATE drive that appears.
  4. The device asks to restart — tap [Restart].
No SD card needed. v2.0 and earlier do not have this, so those versions need one SD card update first.

SD card .bin

  1. Copy the .bin file to the root folder of a microSD card.
  2. Insert the card and turn the device on.
  3. It updates during boot and restarts.
The firmware file is deleted from the card once the update finishes. You can check the version under Settings → Help.

v2.0b 2026-08-07
  • Sharper pattern detection — Frenzel no longer reads as Valsalva. With a mouthfill held, the pressure floor is already high, and the device was counting the small ripples at that level as equalizations. It then judged the peak as long-held and called it Valsalva. Only real peaks count now. Valenzel reading as Frenzel is fixed too — same cause.
  • Mouthfill is recognised in interval training. Between intervals you bring air up from the lungs into the mouth; Frenzel-shaped segments after that fill are now judged as mouthfill Frenzel.
  • Gentler wording on shallow negative pressure. Instructors differ on how to read a shallow one — some see it as a natural byproduct of the tongue releasing, others hold that none should appear. The wording now reflects both views. Deep or repeated negative pressure is still reported clearly.
  • Fixed: the arrow in the file screens skipped two pages on one tap — equalizing, breathing and settings screens all fixed.
  • The default zoom setting was ignored. With 1/2 or 1/4 set, [Reset] or power on always fell back to 1x. It now starts at the zoom you set.
  • A large empty gap in front of a reference-only trace, most visible at 1/4x. When the trace fits on screen it is now drawn from the left.
  • Handling was hardened for dropping a different file onto the update drive mid-copy.
