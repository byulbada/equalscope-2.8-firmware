Downloads

Copy the firmware file (.bin) to the top level of an SD card and power the device on — it updates itself.

  1. Download the .bin file below.
  2. Copy it to the root folder of a microSD card (not inside a folder).
  3. Insert the card and turn the device on. The update runs automatically and the file is removed when it finishes.
  4. Check the version under Settings → Help.

If you have several firmware files on the card, the device picks the highest version — keep only the one you want.
